## 1. 采点总则

1. **唯一采集面＝timeline 事件流**（L0 §4）：任何指标不得新建采集通道；度量采点域是 timeline 的**只读订阅者**（段2 §3 发布语言关系），零写路径。
2. **唯一例外（读侧派生量）**：过程指标③（等待归宿覆盖率）的判据源＝`deriveWaitingItems` 共用纯函数投影——段3 §1 裁定4 明文「度量域自行调用，不经呈现」；该投影的输入仍是四聚合的持久化事实，不构成新采集面。
3. **窗口常量单源**：7 天窗唯一源＝L0 §4（本件只引用与登记校准结论）；卡滞窗阈值唯一源＝本件 §3（段2 §4「卡滞」行与段3 §8 StallSpec 均声明"窗阈值段4 校准"，故本件为该校准的落点）。
4. **实现位**：全部指标计算落 S7（度量采点域模块）；领域侧标志位（FirstInspectionMark、reopenCount、过期令牌写入计数器、恢复结果键）由其所属阶段保证正确（见计划件 §4）。
5. **本地优先**：仅本地计算与本地呈现，不外发（L0 §4 遥测裁定＋原则6）；不引入自托管遥测栈。

## 2. 三层指标 ↔ 事件映射

### 2.1 北极星（唯一）＝二次委托率

| 项 | 口径 |
|---|---|
| 定义（L0 §4 原文面） | 已收尾委托中，用户在收尾后 **7 天内**再发起新委托的比例（按件计） |
| 采点事件 | 分母←`DelegationAccepted`（收尾态）；分子←该件收尾时刻后 7 天窗内存在**另一件**的 `DelegationCreated` |
| 分母口径（段3 §9 明文） | **＝已收尾件**；**已放弃件不进分母**（`DelegationAbandoned` 不参与北极星） |
| 分子细节 | 重开不新建单（I-14）⇒ `DelegationReopened` **不产** `DelegationCreated`，故重开不计入分子（防虚增，与段2 U4 裁定同向） |
| 当前态处理 | 已收尾后又重开的件：重开期从分母暂时移出，窗满未再重开则回到分母（口径＝"以当前终局态判定"，避免同一件既进分子又进分母的重复计） |
| 唯一源声明 | 定义与 7 天窗＝L0 §4；本行只做可执行化，不改口径 |

### 2.2 过程指标

| # | 指标 | 采点事件 | 可执行口径 | 状态 |
|---|---|---|---|---|
| ① | 问题关闭率 | `DelegationAccepted`／`DelegationRejected`／`DelegationReopened`／`DelegationAbandoned`（未关闭侧，段3 §9） | **分子**＝已收尾∧收尾后 7 天窗内无该件 `DelegationReopened`（窗与北极星同源，L0 §4）；**分母**＝见下方待裁点 | **待用户裁定（口径缺口）** |
| ② | 证据核验动作率 | `EvidenceInspected`（首次打开标志）＋`EvidenceRecorded` | 分子＝`FirstInspectionMark` 非空的证据条数（**首次打开计入，重复打开不计**——段3 §3/§5 明文）；分母＝曾进入待核验态的委托件所引用的证据条数（`ValidClaimSpec` 通过的 evidenceRefs 去重集）。**段4 细化声明**：L0 §4 只定"用户实际点开证据的比例"未定分母，本行为可执行化细化，无上游张力；若用户另有口径以 L0 §4 为准并回段4 改本行 | 细化已定（可执行） |
| ③ | 等待归宿覆盖率 | 采点＝`deriveWaitingItems` 投影（读侧派生量，总则 2）；相关事件＝产生等待的状态转移全族（`DecisionRaised`／`CompletionClaimed`／`DecisionDenied`／`SessionInterrupted`／`StallDetected`／`InstructionQueued`） | **结构性判据，非比率**：投影输出中「无归宿等待数＝0」（I-9）；度量域**终态（收束态）过滤后**计数（段3 §9 明文），过滤谓词＝所属委托处于非收束态（收束态＝已收尾/已归档/已放弃） | 已定（可执行） |

**过程①分母待裁点（段4 出口报告项，我不代裁）**：L0 §4 声明"口径唯一源在本条"且明写「避免退化为'1−放弃率'」，但未写分母；段3 §9 把 `DelegationAbandoned` 标为"未关闭侧"。两种读法：

- **案 A（我推荐）**：分母＝**已收尾件**（与北极星同分母）；`DelegationAbandoned` **不进比率**，另作「未关闭侧计数」旁挂呈现（诊断量）。理由：兑现 L0 "避免退化为 1−放弃率"的明文意图；放弃率升高时该指标数据变稀（诚实反映"没有可评的件"）而非被虚假抬高。
- **案 B**：分母＝已收尾件＋已放弃件（段3 §9 "未关闭侧"的字面读法）。代价：指标部分退化为 1−放弃率，与 L0 §4 的明文意图相左。

裁定影响面：仅本行与 S7 spec 的 DoD 判据；裁 A 则本件零上游改动，裁 B 需在 L0 §4 补一句分母口径（段1 frozen，须用户亲裁＋重过闸）。
