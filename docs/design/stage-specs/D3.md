## 语义裁定（ADR-005 同步——不重复展开）

1. **权威位置**：main 进程 `PlannedFilesStore`（IPlannedFilesRepository 实现——userData 落盘 JSON，configStore 模式：损坏容错/同步写/0600）。renderer 保留 ConversationState.plannedFiles 本地镜像（inPlannedFiles/plannedComplete 同步判定需要），写操作（grantPlan/addPlannedFiles/任务边界重置）经 IPC 同步 main——**失败忽略（镜像优先）**，与 localStorage 断点续做同策略。
2. **跨重启恢复（断点续做迁移）**：plannedFiles + approved 跨重启恢复（批准事实持久化——与问题台账 ProblemSnapshot.authorized 恢复同构）；**任务状态机（goal/plan/resolution 确认态）保持 V1 不跨重启**。新任务（目标确认 = 任务边界）→ 重置（与现有 clearTrust → filesApprovedReset 语义一致）。
3. **三基准统一（未修 1 落地）**：planned（main 权威——绝对路径）/ produced（领域层——绝对路径）/ projectFiles（文件树快照——绝对路径，坑 102 已修）——判定单源 plannedComplete（领域层，既有）；D3 以 L1 断言锁定三集合绝对基准一致 + force_input 打点保留。
4. **filesApprovedRef 演进**：main tools.ts 布尔镜像由 store 驱动（add → true；reset → false）——write 门控逻辑不变（`!filesApprovedRef && !opts.approved`）。
