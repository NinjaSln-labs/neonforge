# Stage S4 Spec（完成证据对账）

> 来源：docs/design/intent-confirmation-domain-design.md §6 S4 + §3.3 verifyCompletion（V1a 系统代跑/V1b diff 派生）+ §3.5 completion.evidence_missing 事件 + S3 边界（「不接完成证据对账 UI = S4」）+ A-010。
> 状态：定稿（2026-08-16 开工）。
> 前置：S1 领域层（verifyCompletion 纯逻辑 + SystemVerifier 接口已就位——L1 8 用例）+ S2 解析器（parseCompletionClaim）+ ADR-004（领域层同步消费快照——IO 归应用层）+ S3 接线（resolution 卡从 decisionContent 派生——dcKind 触发已就位；S3 边界明示「resolution 卡确认条件仍为旧 producedFiles 检查——verifyCompletion 消费 = S4」）。
> 本阶段核心：**不变量 4（无证据不进入对账）落到接线**——已解决卡条件 = verifyCompletion 通过；V1a/V1b 系统核验由 main 提供真实 SystemVerifier；证据不足 → 不弹卡 + evidence_missing 打点 + 回填引导。

## DoD（机器可验证断言——stage-gate 逐条执行）

- [ ] L1 全量绿：`cd apps/desktop && npx vitest run`（新增用例 ≥12 条——见 TDD 网格；含 A-010 integration：真实只读命令代跑）
- [ ] L2 契约：双 `npx tsc -p tsconfig.json --noEmit` + `npx tsc -p tsconfig.main.json --noEmit` 0 错
- [ ] L3 交互：`npx playwright test --project=interaction`——**相关场景重写后全量回归 ≥36**（旧场景保留 + S4 新场景：证据对账——证据不足→不弹卡→回填引导）
- [ ] Lint 门禁：`npx eslint .` 0 errors；`npm run format:check` 全过
- [ ] 行为验收：
  - [ ] **已解决卡条件 = verifyCompletion 通过**：done 分支 resolution 路径——parseCompletionClaim 后调 `verifyCompletion(claim, systemState)`；`ok=true` → 置 resolution 决策点（弹已解决卡）；`ok=false` → **不置决策点（不弹卡）**（子断言：systemState 缺省 = 纯逻辑判定 S1 兼容——mock/L3 无代跑时走纯逻辑；无 systemState 且纯逻辑 ok 时仍弹卡）
  - [ ] **V1a 系统代跑接线**：main 侧 `runVerificationCommands`（只读白名单过滤——isSystemVerifiable 领域层判定，main 侧再校验 fail-closed；超时 5s；输出截断；串行执行）→ `verificationResults` 快照 → renderer 经 IPC 获取 → verifyCompletion 消费（ADR-004：领域层同步消费快照，IO 在应用层——代跑结果表进领域层判定）
  - [ ] **V1b diff 派生接线**：`deriveDiffs(plannedFiles, producedFiles)` 系统派生（集合差——produced 由 applyToolResult 维护）→ planned 有文件未产出 → missing（`diff:planned-not-produced`）
  - [ ] **completion.evidence_missing 打点**：登记 `TIMELINE_EVENT_SPECS`（domain 'completion' 成员入联合 + detailKeys 含 missing/unverifiable）+ 接线处 tlog（ok:false 时带 missing/unverifiable 清单）
  - [ ] **证据不足回填引导**：ok=false → 引导文本注入（missing/unverifiable 清单——纯函数 `buildEvidenceBackfill` L1 可测）→ 模型重新输出带证据的完成声明（L3 场景：引导后重输出 → 弹卡）
- [ ] 审计状态：A-010 fixed（本阶段项——V1a integration 测试闭环）；其余 open 项（如有）fixed/recorded
- [ ] 覆盖矩阵已更新（S4 新增用例 + completion.evidence_missing 事件断言）
- [ ] 决策日志同步：本阶段裁定 → docs/decisions/ 有 ADR（如有）
- [ ] 已 push + CI 绿（qa.yml run）

## 边界（不做——防蔓延）

- 不替换 forceTool（decideProgressGuarantee = S5）
- main preApproval/actionGate/classifyReadonly 升级不动（S6——S4 只消费 isSystemVerifiable 白名单）
- 非只读验证命令不代跑（拍板 4——unverifiable 标记 + 引导文本提及「未经系统核验」；「用户对账时显式提示」UI 深化 = S7 或观察）
- 不引入新的验证命令执行器 UI（L3 场景走 mock——真实代跑由 A-010 integration 测试承载）
- L4/L5 不跑（S7 全链）

- 事件 `gate.denied`（§3.5）不登记（S6——actionGate 接入时）
