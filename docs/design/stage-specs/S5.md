> 来源：docs/design/intent-confirmation-domain-design.md §6 S5 + §3.3 decideProgressGuarantee（不变量 5：推进 ≠ 逼调工具）+ §8.1 B（推进检测统一——TurnProgress 扩展 proposed/providedEvidence + StuckDetector 对齐）+ 表 4「forceTool=required（逼调工具）重设计 → decideProgressGuarantee（逼推进）」。
> 状态：定稿（2026-08-16 开工）。
> 前置：S1 领域层 decideProgressGuarantee 初版（4 维输入——produced/proposed/providedEvidence/toolsAvailable；pending 恒 auto）；S3/S4 接线（dcKind 决策点 + verifyCompletion 证据对账——providedEvidence 维度现实基础）；现有 forceTool 链：renderer → `decideTurnPolicy(buildForceToolInput(s, projectFiles))` → gateway forceTool 参数 + execution.forced/released 事件（S1 起）。
