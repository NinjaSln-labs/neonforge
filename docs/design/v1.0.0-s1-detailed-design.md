## 2. 聚合根与命令签名（S1 薄实现）

命令＝聚合公开方法；违反不变量以类型化 `DomainError` 抛出（拒绝理由入命令回执，I-5/I-15 的呈现源，**不进 timeline**，段3 §5 留痕口径）。VO 全按值不可变。

```ts
// delegation/Delegation.ts
type DelegationState = 'created'|'inProgress'|'pendingDecision'|'pendingClaim'|'pendingVerify'
                     |'awaitingUser'      // 拒绝/中断/卡滞待指令（含三态）
                     |'accepted'|'rejected'|'reopened'|'archived'|'abandoned'; // 终态族
class Delegation {
  readonly delegationId: DelegationId;
  create(intent: Intent): DelegationCreated | never;          // I-6 前置=创建合法
  claimCompletion(claim: Claim): CompletionClaimed | never;   // ValidClaimSpec 过才转 pendingVerify（I-6 无据不核）
  accept(): DelegationAccepted | never;                        // AcceptanceSpec 过（I-16）；否则拒→reject 路径
  reject(reason?: string): DelegationRejected | never;
  reopen(): DelegationReopened | never;                        // 挂原 delegationId、reopenCount+1（I-14）；新建=拒
  archive(): DelegationClosed | never;                         // 终态唯一，更新仍恰一当前终态（I-10）
  abandon(): DelegationAbandoned | never;                      // 终态"已放弃"；三处事件驱动消费见 §6
  // 不变量：I-6 无据不核 / I-10 终态唯一 / I-14 重开挂原单 / I-16 验收前置
}
```
Scope（S1 仅 `initial(): ScopeAmended` 声明 v1 版本、无 AmendScope，修正→S2）／DecisionPoint（`raise/resolve/deny`，`resolve` 幂等首次生效 I-3；作废=终态字段非决议值，由 DelegationAbandoned 事件驱动消费）／Turn（`start/terminal`，I-1 在飞≤1＋I-10 恰一终态＋I-15 拒绝待决守卫＋I-12 中断标记）／InstructionQueue（`enqueue/admit/withdraw`，I-4 至多准入一次＋FIFO；撤回=DelegationAbandoned 事件驱动 markWithdrawn）／EvidenceItem（`record/inspect`，Provenance 类型上恒"系统采集"、不可表达 AI 自述 I-5；`inspect` 记 FirstInspectionMark）签名同范式，逐条对应 §2 表"关键命令/关键不变量"列，不在此重复。

`EvidenceType = '变更集'|'命令输出'|'测试结果'|'验收判据运行结果'`（段3 v1.2 四值）；互斥标记规则：本委托 DoD 验收判据运行产出一律记第 4 值、不记 `测试结果`（单值，S4 接线时落创建机制）。

## 3. 仓储面（`repos/index.ts`，按段3 §7，S1 内存实现）

```ts
interface DelegationRepo { save(d); findById(id): Delegation?; findActive(): Delegation[]; listArchived(): Delegation[] }
interface ScopeRepo { findByDelegation(id): Scope?; appendVersion(v): void }
interface DecisionPointRepo { save; findById; findOpenBy(delegationId, turnId): DecisionPoint[] }
interface TurnRepo { findInFlight(): Turn?; save; findByDelegation(id): Turn[] }        // findInFlight 全局≤1（I-1 读侧）
interface InstructionQueueRepo { enqueue; pending(): QueueItem[]; markAdmitted(id); markWithdrawn(id) } // pending 排除已准入/已撤回，FIFO（I-4）
interface EvidenceRepo { save; findByIds(ids): EvidenceItem[]; findByDelegation(id): EvidenceItem[]; markFirstInspection(id) } // findByIds→ValidClaimSpec；findByDelegation→AcceptanceSpec 限界
interface TimelineRepo { append(event): void; since(seq): TimelineEvent[]; findByDelegation(id): TimelineEvent[] }              // append 仅机制口可调（S-1/I-2）
```
内存实现单线程：`append` 内 `seq` 单调由 `TimelineRepo` 唯一写者维护；追加失败⇒整事务回滚（§6 例外条款）。

## 9. 时序（S1 最小闭环，对齐 §6 事务）

`发起→推进→拍板→核验→收尾` 一条 happy path（`npm run e2e` 双轨：真/假网关）：
1. `delegation:create` → DelegationCreated（聚合＋timeline 同事务）
2. 用户输入 → `turn:start`（I-1 在飞≤1，拒方入队）→ TurnStarted → ApplyChange 经 admissionCheck → ChangeProduced →（证据订阅）EvidenceRecorded
3. `decision:raise`→DecisionRaised（护栏①采点位）→ 用户 `decision:resolve/deny` → DecisionResolved/Denied（Denied→I-15 待决守卫）
4. `claimCompletion`（ValidClaimSpec 过）→ CompletionClaimed → 转 pendingVerify
5. `delegation:accept`（AcceptanceSpec 基线）→ DelegationAccepted（北极星采点位）；拒→DelegationRejected→Reopened
6. 全程 timeline append 唯一口＋seq 单调；UI 显式"未持久化"（F2）
