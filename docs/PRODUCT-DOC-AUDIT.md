## 四、问题

1. **[Critical] README 定位门面与用户裁决冲突**——「工程设计编排 IDE，不是聊天工具」「Agent + 编辑器一体」vs 裁决「AI Agent IDE：对话驱动是基础、内在编排自动推进、编辑器=可选能力」。证据：README L3/L5。影响：项目门面错，一切外部认知（含后续文档）锚定错误。
2. **[Critical] D5 视觉稿全面过期且无废弃标注**——812 行全旧三栏 IDE 布局（搭档面板|编辑器|详情面板）+ 旧色 #252526；与已实施布局 v3 冲突；无「以 visual-direction.md 为准」指引。证据：D5 L67/L180/L207/L291/L328。影响：Figma 视觉稿/后续 UI 会按旧布局做。
3. **[Major] D0 页面规格残留旧布局**——L435「主工作区（搭档面板 + 代码编辑器 + 文件树）」、L59「会写代码的人—看到代码编辑器」（编辑器=主能力表述）、L224「提示条在编辑器底部」。§2 已改三区但 §3 页面规格/§1 原则未同步。
4. **[Major] D1 用户流残留旧布局术语**——L98/L100「详情面板展示」、L102「折叠/展开文件树、搭档面板」（现为会话/产物区）。L95「手动编辑代码（不影响搭档）」✅ 贴定位，保留。
5. **[Major] D2 组件旧色值 + 旧布局术语**——L24 Primary `--nf-blue (#3B82F6)`、L145「搭档面板顶部」、L189 `--nf-bg-selected`——D3 已改（靛 #6366F1/深紫系）未回写 D2。

7. **[Major] product-marketing One-liner 旧表述**——「工程设计编排 IDE，不是聊天工具」——定位与裁决冲突（与 README 同源）。
