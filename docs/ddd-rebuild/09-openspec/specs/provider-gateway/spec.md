# Spec · 模型接入（provider-gateway）

> Bounded Context：BC-05 模型接入
> 聚合：A9 ProviderProfile（配置侧）、A10 ChatStream（运行时）
> 本 Spec 只描述业务规则与不变量；SSE/HTTP 细节见 `../../design.md`。

---

## Requirement: 接入方与模型解析

系统应支持多种 OpenAI Chat Completions 兼容接入方，并按用户选择解析出生效的接入方、模型与端点。

### Scenario: 解析默认接入方

- **Given** 用户只配置了一个接入方
- **When** 发起对话
- **Then** 系统使用该接入方与其默认模型
- **And** 端点由接入方描述符给出，不由模型名推断

### Scenario: 切换模型

- **Given** 接入方支持多个模型
- **When** 用户选择另一个模型
- **Then** 后续对话使用新模型
- **And** 已在进行中的流不受影响

### Scenario: 接入方缺少必要配置

- **Given** 接入方缺少端点或密钥
- **When** 发起对话
- **Then** 系统拒绝发起并返回可执行的配置引导
- **And** 不发起半配置请求

### Scenario: 未知接入方

- **Given** 配置引用了不存在的接入方
- **When** 解析
- **Then** 系统回退到内置默认接入方，并记录降级说明

## Requirement: 流式对话与重试

系统应流式返回推理与正文增量，并在可重试错误上按规则重试；已推送的增量不得在重试后重复。

### Scenario: 正常流式返回

- **Given** 接入方返回 SSE 增量
- **When** 系统接收
- **Then** 推理增量与正文增量分别送达界面
- **And** 流结束时以完成事件收口

### Scenario: 可重试失败

- **Given** 请求遇到超时、5xx 或网络错误
- **When** 未超过重试上限
- **Then** 系统重试同一请求
- **And** 若已推送过增量，先发送“流重置”再重新累积

### Scenario: 参数错误

- **Given** 请求返回 400
- **When** 系统处理
- **Then** 系统最多重试一次（用于修正请求形态）
- **And** 再次失败则把错误分类返回给界面

### Scenario: 重试耗尽

- **Given** 重试达到上限仍失败
- **When** 系统放弃
- **Then** 返回分类错误（鉴权/限流/超时/网络/服务端）
- **And** 已产出的完整增量不被丢弃（保留可读部分）

### Scenario: 用户取消

- **Given** 流正在进行
- **When** 用户取消
- **Then** 请求中止，不触发重试
- **And** 界面显示已取消而不是失败

## Requirement: 工具调用修复

系统应容忍模型返回的常见工具调用形态偏差，并在修复失败时明确拒绝而不是静默执行错误参数。

### Scenario: 参数为 JSON 字符串

- **Given** 模型把工具参数作为字符串返回
- **When** 系统累积工具调用
- **Then** 系统解析该字符串为对象
- **And** 解析失败时保留原文并标记为不可执行

### Scenario: 工具名缺失

- **Given** 增量中缺少工具名
- **When** 系统收口工具调用
- **Then** 该调用被判为无效，不猜测工具名

### Scenario: 多个工具调用

- **Given** 一次响应包含多个工具调用
- **When** 系统累积
- **Then** 按索引分别拼接参数
- **And** 每个调用独立校验

## Requirement: 密钥验证与模型刷新

系统应允许用户验证接入方密钥并刷新可用模型；验证失败必须给出分类原因，不得把网络错误说成密钥错误。

### Scenario: 验证成功

- **Given** 用户输入密钥并请求验证
- **When** 接入方鉴权通过
- **Then** 返回可用模型列表并标记密钥有效

### Scenario: 鉴权失败

- **Given** 接入方返回 401/403
- **When** 验证
- **Then** 返回“密钥无效”，不修改已保存的配置

### Scenario: 网络失败

- **Given** 验证请求超时或网络不可达
- **When** 验证
- **Then** 返回“网络/端点不可达”，与密钥无效区分

### Scenario: 刷新模型列表

- **Given** 密钥有效
- **When** 用户刷新模型
- **Then** 系统从接入方拉取模型并合并内置模型描述
- **And** 拉取失败时保留上一次可用列表

## Requirement: 预热与摘要

系统应支持轻量预热与对话摘要，二者失败不得阻断主对话。

### Scenario: 预热

- **Given** 应用启动且配置完整
- **When** 触发预热
- **Then** 系统发起一次轻量请求以预热连接
- **And** 预热失败只记录状态，不弹错误

### Scenario: 长对话摘要

- **Given** 对话超过压缩阈值
- **When** 请求摘要
- **Then** 系统用当前模型生成摘要
- **And** 摘要失败时保留原始消息，不丢失上下文

## 校验

- [x] Requirement 粒度：解析、流式、修复、验证、预热各自独立
- [x] 每个 Requirement 的 Scenario 数 ≤ 5（解析 4、流式 5、修复 3、验证 4、预热 2）
- [x] 错误分类（鉴权/网络/超时）在 Scenario 中可区分
- [x] Scenario 未渗入具体 HTTP 库或框架细节
