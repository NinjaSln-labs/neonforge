# Spec · 配置与凭据（configuration-secrets）

> Bounded Context：BC-07 配置与凭据
> 聚合：A9 ProviderProfile
> 本 Spec 只描述业务规则与不变量；存储细节见 `../../design.md`。

---

## Requirement: 凭据存储

系统应在本机安全存储用户凭据；仓库、日志与导出中只允许出现环境变量名或凭据文件路径，绝不写入凭据值。

### Scenario: 保存密钥

- **Given** 用户输入接入方密钥
- **When** 保存配置
- **Then** 密钥只保存在本机配置存储中
- **And** 界面以掩码展示，不回显完整值

### Scenario: 安全存储不可用

- **Given** 系统安全存储不可用
- **When** 保存密钥
- **Then** 按明确降级策略保存，并在界面标注降级状态
- **And** 不把密钥写入日志或导出

### Scenario: 日志与导出脱敏

- **Given** 任意日志或导出动作
- **When** 生成内容
- **Then** 密钥字段被省略或掩码
- **And** 请求头中的鉴权信息不落盘

### Scenario: 仓库规则

- **Given** 项目仓库中的任何文档或脚本
- **When** 引用凭据
- **Then** 只引用环境变量名或本机凭据文件路径
- **And** 不出现凭据值

## Requirement: 接入方与模型配置

系统应允许用户配置接入方端点、密钥引用与默认模型，并对配置做有效性校验。

### Scenario: 新增接入方

- **Given** 用户提供端点与密钥引用
- **When** 保存
- **Then** 接入方进入配置并可用于对话
- **And** 端点必须是合法 URL

### Scenario: 修改默认模型

- **Given** 接入方有多个模型
- **When** 用户修改默认模型
- **Then** 后续对话使用新默认值
- **And** 配置持久化到本机

### Scenario: 无效端点

- **Given** 端点不是 http/https URL
- **When** 保存
- **Then** 系统拒绝并提示修正
- **And** 旧配置不被覆盖

### Scenario: 删除接入方

- **Given** 接入方仍被选为默认
- **When** 用户删除
- **Then** 系统回退到内置默认接入方
- **And** 不留下悬空引用

---

## Requirement: 配置读取与容错

系统应在启动时读取本机配置，损坏或缺失时回退默认值且不阻断启动。

### Scenario: 正常读取

- **Given** 配置文件存在且合法
- **When** 应用启动
- **Then** 配置被加载并生效

### Scenario: 文件损坏

- **Given** 配置文件无法解析
- **When** 应用启动
- **Then** 系统使用默认配置并保留损坏文件以便排查
- **And** 不阻断用户开始使用

### Scenario: 文件缺失

- **Given** 首次启动没有配置文件
- **When** 读取
- **Then** 返回默认配置，首次保存时创建文件

### Scenario: 部分字段缺失

- **Given** 配置缺少可选字段
- **When** 读取
- **Then** 缺失字段使用默认值，已有字段不被重置

---

## Requirement: 环境变量与凭据文件引用

系统应支持以环境变量名或本机凭据文件路径引用密钥，并在解析失败时给出可执行提示。

### Scenario: 环境变量引用

- **Given** 配置以环境变量名引用密钥
- **When** 发起对话
- **Then** 系统从进程环境解析该变量
- **And** 变量缺失时返回“未配置密钥”，不发起请求

### Scenario: 凭据文件引用

- **Given** 配置以本机文件路径引用密钥
- **When** 发起对话
- **Then** 系统读取该文件并仅用于本次请求
- **And** 文件不可读时给出路径级错误

### Scenario: 值混入配置

- **Given** 用户误把密钥值直接写进可导出的配置字段
- **When** 保存
- **Then** 系统按密钥处理并掩码，不进入日志/导出

---

## Requirement: 配置变更生效

系统应让配置变更在后续请求中生效，不影响正在进行的流。

### Scenario: 修改后生效

- **Given** 用户修改接入方或模型
- **When** 下一次请求发起
- **Then** 使用新配置
- **And** 当前进行中的流不受影响

### Scenario: 配置热读取

- **Given** 配置在运行时被更新
- **When** 系统读取
- **Then** 读取到最新值，无需重启
