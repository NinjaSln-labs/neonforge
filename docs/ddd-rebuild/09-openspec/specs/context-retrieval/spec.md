# Spec · 上下文与检索（context-retrieval）

> Bounded Context：BC-08 上下文与检索
> 聚合：A11 ContextBundle
> 本 Spec 只描述业务规则与不变量；索引/协议细节见 `../../design.md`。

---

## Requirement: 引用注入

系统应把用户 @mention 的文件与目录内容作为上下文注入对话，并受令牌预算约束。

### Scenario: 引用文件

- **Given** 用户 @mention 一个项目内文件
- **When** 发送消息
- **Then** 文件内容被注入本轮上下文
- **And** 消息中保留可读的引用标记

### Scenario: 引用目录

- **Given** 用户 @mention 一个目录
- **When** 发送消息
- **Then** 目录内匹配文件按规则被注入
- **And** 超出预算时截断并标注

### Scenario: 引用不存在

- **Given** 用户 @mention 不存在的路径
- **When** 发送消息
- **Then** 系统跳过该引用并提示未找到
- **And** 不阻断本轮发送

### Scenario: 预算耗尽

- **Given** 引用内容超过上下文预算
- **When** 组装上下文
- **Then** 按优先级保留引用并截断其余
- **And** 截断在界面可见

## Requirement: 代码检索

系统应支持基于项目的代码检索，为搭档提供相关片段；检索失败不得阻断主对话。

### Scenario: 检索命中

- **Given** 项目已建立检索索引
- **When** 搭档或用户发起检索
- **Then** 返回相关文件片段与位置
- **And** 结果按相关度排序

### Scenario: 索引缺失

- **Given** 检索索引尚未建立
- **When** 发起检索
- **Then** 系统返回“索引不可用”并建议建立索引
- **And** 不静默返回空结果冒充命中

### Scenario: 检索无命中

- **Given** 索引可用
- **When** 查询无匹配
- **Then** 明确返回空结果，不伪造片段

### Scenario: 检索失败降级

- **Given** 检索过程出错
- **When** 主对话继续
- **Then** 跳过检索结果，主对话不受阻断
- **And** 记录错误供排查

## Requirement: 符号查询

系统应支持语言服务级符号查询，用于定义/引用定位；语言服务不可用时明确降级。

### Scenario: 定义定位

- **Given** 语言服务对该文件可用
- **When** 查询符号定义
- **Then** 返回定义位置

### Scenario: 引用查询

- **Given** 语言服务可用
- **When** 查询符号引用
- **Then** 返回引用列表

### Scenario: 语言服务不可用

- **Given** 项目语言未安装对应语言服务
- **When** 查询
- **Then** 返回“不可用”并建议安装
- **And** 不退化为全文猜测

---

## Requirement: 长对话压缩

系统应在对话超过阈值时压缩历史，保留决策与最近消息，避免上下文溢出。

### Scenario: 达到阈值

- **Given** 对话消息数超过压缩阈值
- **When** 组装历史
- **Then** 系统生成摘要并保留最近消息与结构化决策
- **And** 摘要不替代未完成的工具调用状态

### Scenario: 未达阈值

- **Given** 对话消息数未超过阈值
- **When** 组装历史
- **Then** 原样传递，不触发压缩

### Scenario: 压缩失败

- **Given** 摘要生成失败
- **When** 组装历史
- **Then** 保留原始消息并继续，不丢上下文

---

## Requirement: 预热

系统应支持在项目打开后预热检索与模型连接，提升首次响应速度；预热失败不影响正常使用。

### Scenario: 预热成功

- **Given** 项目已打开且配置完整
- **When** 触发预热
- **Then** 检索索引与模型连接被预热
- **And** 界面可见预热状态

### Scenario: 预热进行中重复触发

- **Given** 预热已在进行
- **When** 再次触发
- **Then** 复用进行中的预热，不重复启动

### Scenario: 预热失败

- **Given** 预热过程出错
- **When** 用户继续使用
- **Then** 功能可用，仅缺少预热收益
- **And** 错误被记录而不弹窗阻塞

---

## 校验

- [x] Requirement 粒度：注入、检索、符号、压缩、预热各自独立
- [x] 每个 Requirement 的 Scenario 数 ≤ 5（注入 4、检索 4、符号 3、压缩 3、预热 3）
- [x] “失败不阻断主对话”的降级原则贯穿全部 Requirement
- [x] Scenario 未渗入向量库/语言服务协议等技术细节
