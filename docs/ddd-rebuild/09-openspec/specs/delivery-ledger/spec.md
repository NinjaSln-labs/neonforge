# Spec · 交付与问题台账（delivery-ledger）

> Bounded Context：BC-04 交付与问题台账
> 聚合：A6 ProblemInstance、A7 DeliveryPackage
> 本 Spec 只描述业务规则与不变量；IPC/存储/框架细节见 `../../design.md`。

## Requirement: 交付包生成

系统应把真实完成的文件变更汇总为交付包，包含人话摘要、产物清单、验收对照与下一步；不得用模型声明替代真实产物。

### Scenario: 真实变更生成交付包

- **Given** 搭档成功写入或编辑了至少一个文件
- **When** 系统更新交付包
- **Then** 交付包包含摘要、真实产物清单与复跑入口
- **And** 产物清单来自真实文件变更，而不是模型自述

### Scenario: 无真实变更

- **Given** 没有任何真实文件变更
- **When** 系统考虑生成交付包
- **Then** 不生成虚假交付包
- **And** 用户看到的仍是空态或上一次的真实交付

### Scenario: 验收对照为空

- **Given** 本次任务没有可用的验收标准来源
- **When** 生成交付包
- **Then** 验收对照显式为空，而不是伪造“全部通过”

### Scenario: 演示数据隔离

- **Given** 产品运行时没有演示注入
- **When** 渲染交付/DoD/数字交付区域
- **Then** 演示面板不得出现
- **And** 真实交付包只由真实变更生成

## Requirement: Diff 应用与回滚

系统应允许用户审核并应用文件 diff；应用前必须快照，回滚必须恢复原样。

### Scenario: 应用 diff

- **Given** 用户已审核一个合法 diff 并授权
- **When** 应用
- **Then** 目标文件被更新，系统保留应用前快照
- **And** 交付包显示该文件为“已应用”

### Scenario: 拒绝 diff

- **Given** 用户拒绝一个 diff
- **When** 用户选择拒绝
- **Then** 文件不发生变化
- **And** 交付包显示该文件为“已拒绝/未应用”

### Scenario: 回滚 diff

- **Given** 文件已应用 diff 且有快照
- **When** 用户选择回滚
- **Then** 文件恢复为应用前内容
- **And** 交付包状态回到未应用

### Scenario: diff 格式不支持

- **Given** diff 无法解析或没有变更
- **When** 应用
- **Then** 系统返回“不支持该格式”，不修改文件

### Scenario: 文件不存在

- **Given** diff 目标文件不存在
- **When** 应用
- **Then** 系统返回错误，不创建伪造文件

## Requirement: 问题台账

系统应把每个用户问题作为一等公民，维护 7 态状态机与断点快照；问题可复跑、可关闭。

### Scenario: 创建问题

- **Given** 用户发送一条新问题
- **When** 系统创建问题实例
- **Then** 问题进入“执行中”状态，快照记录目标首句
- **And** 问题出现在台账中

### Scenario: 同标题复跑

- **Given** 台账中已存在同标题问题
- **When** 用户再次发送同标题问题
- **Then** 系统更新原问题而不是新增重复项
- **And** 保留原快照并追加待办

### Scenario: 更新快照

- **Given** 问题执行过程中目标确认或工具授权成功
- **When** 快照更新
- **Then** 目标/已授权操作/待办被记录
- **And** 旧版授权的字符串形态被迁移为结构化记录

### Scenario: 关闭问题

- **Given** 用户已确认交付包
- **When** 用户关闭问题
- **Then** 问题进入“已关闭”终态
- **And** 交付包状态同步为已关闭

### Scenario: 台账容量

- **Given** 台账已有很多问题
- **When** 新增问题
- **Then** 只保留最近的问题，避免无限膨胀
- **And** 旧问题不被静默破坏（按存储上限截取）

---

## Requirement: 复跑与断点续做

系统应允许用户从问题台账恢复上下文，或在问题关闭后重新执行同一问题。

### Scenario: 选择已关闭问题

- **Given** 问题已关闭且存在快照
- **When** 用户选择该问题
- **Then** 系统展示目标、已授权操作与待办
- **And** 提供复跑入口

### Scenario: 复跑

- **Given** 用户选择复跑
- **When** 复跑开始
- **Then** 以原问题标题作为新的请求重新发送
- **And** 原问题状态回到执行中

### Scenario: 快照缺失

- **Given** 旧问题没有快照
- **When** 用户选择该问题
- **Then** 系统仍可展示标题与状态，不伪造快照内容
