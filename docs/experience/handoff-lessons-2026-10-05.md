## A. 方法与判据（十二族）

**A1 同名异指＝第二权威源，落笔前先"词查"。** 新词进模型前全库 grep 该词的中英文全部用法。三个撞名全是提案通过之后才被抓到：`TurnProgress` 名实不符（字段实为往返级＋Task 级混合）、Timeline 的「步骤」是比往返更细的记录单位、`IntentConfirmationServices` 的"意图"指确认意图而非发送意图。⇒ 粒度阶梯唯一化（Task⊃Turn⊃Round⊃动作），新词与既有词错开，既有 VO 发改名令。`p000159`

**A2 外部结论入库前做三查：射程／族／承载点。** ①**射程查**——被引 ADR／条款要先 grep 它到底管不管这件事（曾替 ADR-017 造出一条它从未写过的"busy 例外"，后续审计就反按这条要求行事）；②**族查**——决策面至少三族（确认卡／system_clarify／授权窗），A 族的修法打到 B 族就是新造死锁；③**承载点查**——同一语义常有两处载体（同一判定既在即时分流又在入队归属冻结），只改一处＝换个地方继续活着。对抗审计的产出同样要过这三查，**不能整把采信**。`p000158`

**A3 落位≠落地，声明≠事实。** 提交信息里每一项出口声明，落笔前先 `git show --stat` 加逐条 grep。真实事故：一条 commit 声明三件事——coverage 表追加四项（该文件 diff 为空）、两行对账（四列写进两列表，表格结构断裂）、修复某 P0（三处互斥谓词只补了一处，另一句按定义永不自真＝死锁读法）。根因＝以会话记忆作声明来源。`p000161`

**A4 混轴＝造不出门。** 同一枚举承载两根轴时，缺陷关不掉。已确认的三处混轴：把**实例身份**与**协商计数**混为一根（导致"迟到答复该不该作废"判据自相矛盾）；把**决定轴**（未决／已批／过期）与**焦点轴**（现在轮到谁／还在排队）压进一个枚举，且派生值被物化存储（多出"谁忘了重算"这一族故障）；把 **Turn 归属**写成渲染层私有游标代职。⇒ 先分轴，再谈不变量；派生值不入库。

**A5 迟到文本族的成因形状（同一病症三种表现）。** 共同成因＝**并行＋异步窗＋把换代绑在内容上**。三个具体教训：①核验引导与主链并行时，失败引导可在成功卡已 pending 后迟到发出并起新回合锁死点卡——测 timeout 且尾态出现过收口卡，先查这类系统 nudge 再怪排队或 harness；②审批 allow 路径从不走"决策落定"，pending→none 靠异步 clearPending，异步窗内迟到文本照样命中＝同族旁路；③**换代必须绑用户行为、不能绑内容**——按"内容实质变化才换代"写，则每次摘要必变→同代次成死代码→把用户对着旧卡的有效延迟答复误作废。另：文本 flush 路上的归属门若拿的是当前值，守卫恒真、永不触发（按钮路与文本路两把刀不可互替）。`p000140` `p000142` `p000149` `p000147` `p000150` `p000151`

**A6 判定力有下限。** ①稳定红＝**N≥3 次运行的交集**，flake 单列；②孤例跑法必出假绿——单例 `-g` 跑法因负载不足常绿，同一刀整轮冷启才红，红点还在族内轮换；③**harness 结构会伪装成产品缺陷**——插话"被吞"多半是自动化脚本的门顺序（外层 busy 门在插话块之前）导致窗口不存在，判产品问题前先确认是真 busy；④同命令串行两次结果不同且本就 workers:1 ⇒ 不是并发假失败，是该套对机器负载／时序敏感。`p000145` `p000154` `p000141`

**A7 测完再修是硬闸。** 整轮测批进行中与刚结束未获用户裁决前，**禁止改产品、harness、断言**；只记 → 汇总 → 待裁 → 另开修批 → 另开回归。它压过"方案关单未达标就再修一刀"的冲动，也压过会话里顺手修误杀。全文见 `docs/decisions/012`，其它文档只引用编号不另写细则。

**A8 引用实现前先 grep 实现。** 文档／契约里的 CSS 类名、Timeline 事件名、字段名，核实不了就标「待规格」，不许当既成事实写进验收断言。真实例：一个选择器只活在注释里（DOM 真名不同），导致断言结构性不可测；一条契约引用了本文不存在的章节号（悬空引用）。`p000157`

**A9 外部快照先确认可信面。** 竞品／第三方源码调研前先确认手上是**客户端还是运行时**（全仓 `.py` 数量、README 是快速判据）——从前端 canvas 得出的后端结论属产品名错引。竞品语义进自家文档前先对**底线条款**（例如某竞品"直接丢弃不记录也不排队"与产品契约"任何一态都不得丢弃输入"正面冲突，只能采有痕拒绝）。`p000156`

**A10 溶解优先于新建本体。** 三个词被裁掉：**暂停**（领域只有继续／停止，"被按住的原轮"不存在，恢复永远是新轮）、**撤销**（批准出去的动作不可追回，只能打断正在跑的轮；收回已写入的文件＝按文件回滚，唯一机制 `.nf-bak`）、**部署**（它是 bash 高危命令子类，逐次单独确认，不建持久授权档）。方法＝ADR-016 规则 4「错位走溶解」。⇒ 遇到"感觉词"先问：移除后谁兜底？兜得住就溶解，兜不住才建本体。`docs/decisions/023`

**A11 重构＝新树，旧文只读。** 不在旧树上打第三十处补丁层；新设计一律进新树，引用旧文必带冻结 commit 号。旧权威文本定位＝**一次性供体**，其价值是经验与基线而非现行依据；九轮修订逐层叠加、只加不核就是它的病根。配套：**停止追加人工审计轮**，治理改为**写时过闸**（落笔即过两问：移除后谁兜底／属于哪根轴；答不出只能以 ⏳需详设 存在，不得写成陈述句），落位批 DoD 用可跑的机验清单。`p000162` · `docs/decisions/025` 前置裁定 · 概念账本见 `docs/design/domain-model-reconstruction-design-2026-10-05.md`

**A12 台账的单一写入口是防护，不是格式。** 绕过 CLI 直写交接文件＝把一次未记录改动藏进存储：写前快照与写事件日志是唯一回滚依据与旁证链，手改会让"幂等确认"变成既成事实假象。判据红且不确定成因时，先查写事件日志的旁证字段，别猜。`p000163`

## B. 环境例外（仍然有效的硬事实）

**环境重建后必查三样**（npm 的 omit-dev 与 allow-scripts 都**静默**失败）：①devDeps 是否装齐（全局 `NODE_ENV=production` 会让 `npm install` 只装生产依赖，vitest/playwright/typescript 全缺；验证链运行时也须 `env -u NODE_ENV`）②Electron 二进制是否存在（被 allow-scripts 拦时 `ELECTRON_MIRROR=<npmmirror> node node_modules/electron/install.js`）③git hooks 是否装好（lefthook postinstall 同被拦 ⇒ `npx lefthook install`；本机 `core.hooksPath=.githooks` 与私有钩子共存）。`p000122`

**Mac 侧**：①无「屏幕录制」权限时 `screencapture` 只拍到壁纸——绕过用 CDP（端口转发＋`connectOverCDP`，可截屏也可驱动 UI）；②`git pull` 会**静默**失败（SSL 抖动或被本地改动挡住快进），错误被管道吞 ⇒ 构建出旧代码；加固姿势＝stash→pull→pop，**构建后 grep asar 里的关键符号**再安装；③`/tmp` 周期清理会吃掉 UAT 现场的 `node_modules`（日志与 asar 幸存），重跑前先查 `.bin` 在不在，别信上次的检查结果；④非交互 ssh 里没有 npm（须 source nvm）；⑤Mac 常连不上某些外网探测域名而 WSL 可得 202 ⇒ 外网探活的结论要按出口分别判，别拿一侧的失败当产品缺陷。`p000118` `p000119` `p000137` `p000126` `p000132`

**Electron 与构建**：①应用级**单实例锁**——e2e 每场景 launch 新实例必须等前一实例完全 close，残留实例会锁死后续场景；②dev 的 userData 目录名取 `package.json` 的 name（不是「Electron」），清缓存要删对目录；③`electron-builder` 直接跑会用**陈旧的 dist** 打包（不清不重建＝dmg 里是旧代码），真机打包一律走 `npm run dist` 或先清 `dist release`；④preload 必须 CJS 且 esbuild 要 `--external:electron`；⑤启动务必 `env -u ELECTRON_RUN_AS_NODE`。`p000016` `p000024` `p000116` `p000003` `p000006` `p000007`

**测试基建**：①**测试隔离**是根因分析第一步——加载用户真实会话会让旧上下文污染模型行为，通过和失败都可能是假象（独立 userData 也顺带解单实例锁冲突）；②L3 warmup 必须带 mock 桥再预热，否则应用落到"无 key"配置页、挂载门永不出现；webServer 探活只测端口，vite 冷编译发生在首个浏览器页面 ⇒ 归因批每轮 kill 测试端口取最坏冷启；③端口独占：demo 与测试各占一口，占端口先 kill；④**L5 视觉基线禁止在 Linux／WSL 跑 `--update-snapshots` 入库**，权威宿主是 macOS；⑤验证链**串行执行**——eslint 与 playwright 同跑会产生资源竞争型假失败；⑥渲染层 `console.log` 不进 app stdout（Electron 只转主进程）⇒ 停滞取证直接用 CDP 读 DOM，幽灵气泡这类渲染残留只有 DOM 能看见；⑦取证脚本必须放在项目目录内跑（ESM 按脚本所在路径解析 `node_modules`，放 `/tmp` 从项目 cwd 跑仍报找不到模块）。`p000085` `p000153` `p000009` `p000136` `p000114` `p000139` `p000138`

**Shell 与工具链**：①bash heredoc 里的引号／反引号会触发命令替换打断参数（长文本一律走 `--from-file`，且 `handoff` 报 ok 也可能条目已丢）；②复合命令链中 `pkill` 会吞掉后续命令，分步执行；③`git checkout`／`stash` 做隔离实验后必须 diff 复核（还原时漏加回来的用例＝自伤型红）；④以 `../` 相对路径让 prettier 匹配仓库根文件会报无匹配，改用它自带的 bin 加绝对路径。`p000112` `p000123` `p000113` `p000115`

## D. 本文剔除了什么（可审计的取舍）
