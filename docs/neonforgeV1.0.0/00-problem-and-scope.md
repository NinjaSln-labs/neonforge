## 1. 问题陈述与价值陈述

**问题陈述**：把一件真实的活儿委托给 AI agent 时，用户无法信任它的过程——它说"做完了"却可能没做、它"在想"却可能卡死、它要授权却说不清为了什么。委托退化成全程盯着＋手动复核，省力变成费力。

**价值陈述**：让人机协作的过程可信——每个承诺有主、每次等待有因、每个"已完成"有可核验的证据，用户能放心把注意力移开。

> `[裁定 A]` 问题的**定性框架**＝**信任/可信**（用户 2026-10-05 裁）：核心痛点定为过程不透明、承诺不可核验，而非"能力不够强"或"不够听话"。差异化落点＝可核验的人机协作，避开与大厂拼能力/控制的主战场。

## 2. 目标 / 非目标（V1.0.0 射程）

### 目标（V1 要做到的）

- G1 委托一件**有明确产物、产物可核验**的工作给 AI，全程看得见进程与归属。 `[裁定 B：先窄后宽]`
- G2 每一次"AI 需要用户拍板"都有独立、不丢、不错位的归宿（授权/决策点）。
- G3 每一个"AI 声称完成"都能被用户一键核验到证据（改了什么、跑了什么、结果如何）。
- G4 单用户单视图：一个用户管理自己委托出去的活儿，不需要协作/多租户。

### 非目标（V1 明确不做——防范围蔓延）

- N1 不做**开发者面/多 Agent 编排/专用部署通道**（超出 V1.0.0 射程，另立版本树；ARCHIVE-INDEX 第 3 条）。
- N2 不做**多人协作/团队/企业权限**（V1＝单用户）。
- N3 不做**通用聊天/问答助手**——NeonForge 只对"委托一件有产物的活儿"负责，不承接无产物的闲聊。 `[建议]`
- N4 不做**模型训练/微调/自有模型**——只做编排与可信呈现，模型是外部供给。 `[建议]`
- N5 不做**移动端/Web 云端**——V1 形态＝桌面（Electron，见约束 C1）。 `[裁定 C：桌面 Electron]`

> `[裁定 B]` **Job 射程＝③先窄后宽**（用户 2026-10-05 裁）：V1 锚定**软件工程委托**（写/改代码、跑测试——产物＝代码变更，diff/测试结果天然可核验，证据最硬）；可信纪律（轮次/驱动权/授权/证据）**设计成通用**，②通用知识工作、其他域留后续版本树横向扩。理由：差异化（可信）是通用的，但 V1 必须有一个证据能真闭环的域把纪律跑通，软件工程域证据最硬、旧树领域资产可复用（只作经验、不作依据）。对冲 R2：不选②通用知识工作，因其产物多样、证据难统一核验。

## 4. 术语种子清单（≥10；歧义点须标注——旧树"感觉词未成谓词"教训）

| 术语 | 定义候选（V1 起步） | 歧义点 | 所属轴/场景 |
|---|---|---|---|
| 委托（Delegation） | 用户把一件有产物的活儿交给 AI 的完整生命周期 | 与"任务""会话"边界不清 | 任务轴 |
| 轮次（Turn/Round） | 一次"用户输入→AI 推进→需用户下一步"的推进单元 | Turn vs Round 旧树曾同名异指 | 推进轴 |
| 驱动权（Driver） | 当前谁在推进这轮（AI 自动 / 等用户） | "驱动"易与"触发"混 | 推进轴 |
| 授权（Authorization） | AI 需要用户批准才能继续的决策点 | 与"确认""批准"三词旧树混用 | 授权轴 |
| 决策点（Decision Point） | 呈现给用户、需其拍板的卡片/选项 | 与"授权"是否同类，留段2 定 | 授权轴 |
| 证据（Evidence） | 支撑"已完成"声称的可核验产物（diff/日志/结果） | "证据"范围＝？改动/输出/二者 | 证据轴 |
| 承诺（Claim/Commitment） | AI 声称"我做了/将做 X" | 与"产物""结果"边界 | 证据轴 |
| 等待项（Waiting Item） | 任何"卡在等某人/某事"的可见归宿 | 旧树五处各造词汇 | 等待轴 |
| 焦点（Focus） | 多个等待项中当前该看哪个 | 焦点 vs 优先级 vs 默认选中 | 焦点轴 |
| 产物（Artifact） | 委托最终交付的东西 | 产物 vs 证据 vs 输出 | 产物轴 |
| 假推进（Fake Progress） | AI 显得在动、实际无有效进展 | 旧树未成谓词的典型感觉词 | 呈现轴 |
| 作用域（Scope） | 一次委托允许 AI 触及的边界（文件/命令/网络） | 与"沙箱""权限"混 | 作用域轴 |

> `[裁定 D]` 术语种子在段0 **只登记歧义**（有哪些轴＋歧义在哪），**定义权留段2 领域战略逐词定谓词**（用户 2026-10-05 裁）。守 ADR-026 铁律②禁跨段：段0 不越权做段2 的定义事。旧树"感觉词未成谓词"教训（假推进/高危/越界等）在此显式承接——这些词在段2 成谓词前不得进不变量条文（ARCHIVE-INDEX §3.3）。
