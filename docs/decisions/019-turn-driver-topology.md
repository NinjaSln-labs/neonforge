# ADR-019：驱动拓扑裁定——入口唯一消费者＋同步取消令牌（现状判为实现偏离）

- 状态: accepted（2026-10-04 用户裁定方向；本 ADR 由合作负责人落笔，范围限于"性质判定＋批次划分"，不含实现设计）
- 日期: 2026-10-04
- 相关: `docs/audits/stage-c-precheck-confirm-round-ownership-2026-10-03.md`（本 ADR 重述其 §4 落点性质）、`docs/audits/stage-c-deviation-vs-gap-2026-10-04.md`（分家表 D1–D5／G1–G3＋外部佐证全文）、ADR-012、ADR-013、ADR-015、ADR-016、ADR-017、ADR-018、`00 §3.2 规则 2/要点 5`、`02 §4.2/§4.12`、`04 §1.1:14`、`04 §3.2:412`

## Context

S7-1/#7-1 稳定红族已定层为「用户决策后下一模型轮归谁驱动在产品里没有权威归属」。拓扑实测：`ConversationPanel.tsx` 内 **26 个调用点**直调 `send()`（用户/外部 4、按钮回声 8、系统自发轮 13、队列回投 1），`send()` 每次都 `sid = ++sessionRef.current`（`:2734`/`:3041`）立即开启新模型轮，旧轮唯一的自杀点是 500ms poll 里的 sid 比较（`:1993`/`:1995`）；排队消息的 drain 位挂在**链尾 finally**（`:2851`）。

本会话先后试过的两个形状补丁都失败并留下实测数据（A 守卫：族 0 红但 `retry:188` 3/3＋每轮 1 例轮换红；B 回声直送：族 0 红但误杀工具执行链 `core:388`/`factory.self:30`+`:73`/`retry:188` 各 3/3）。两者是同一台机器的两面：**任何在 `send` 单行上的改动都在改全局轮序，而轮序当前没有权威定义处**。

外部佐证（八家竞品源码＋四个框架）：无一采用"多入口各自直接发起在飞链＋轮询发现过期"；一致形态是「意图入队/注入 → 唯一消费者在回合边界决定是否发起下一轮」。同时证伪了一个更激进的读法——**Codex 确有抢占**（`abort_all_tasks(TurnAbortReason::Replaced)`），差别在于抢占集中在单一入口且**同步取消**。

## Decision

1. **性质判定：现行驱动拓扑属实现偏离，不是设计选择。** 判据全部来自现行权威文本，不新增概念：
   - D1 `02 §4.12`「当前回合收口后自动发送」vs drain 位在任意链 finally（孤儿链照样投递）；
   - D2 `00 §3.2 规则 2`「存在活 pending 时用户决策是下一个状态的唯一输入」＋ `04 §3.2:412`「状态机未到下一态——结构性，非拦截」vs 26 处各自开轮＋轮询自查；
   - D3 `00 §3.2 要点 5`「UI 现象不再代理领域状态」已对 pending 裁过一次，working/busy 未贯彻（effect 镜像滞后≈100ms＋三处手动补清）。
     ⇒ 落在 p000128 门槛的"**实现偏离产品定义**"一侧：纠偏不需新设计批准。
2. **目标形态的精确措辞＝「入口唯一消费者 ＋ 同步取消令牌」**，而非"单循环消除抢占"、亦非"禁止代次作废"。抢占合法，但必须①只在仲裁点发生、②同步生效（不留 500ms 的"已过期却仍在写状态"窗口）。
3. **阶 C 拆两批，顺序为硬依赖**：
   - **C-纠偏批**（D1–D3；**显式保留** D4 待授权直送例外与 D5 催推进/对账引导功能，只收编其投递通道）——与 §4.5 C1/C4 落地是同一次改动（21 站点重叠），并刀。
   - **C-补模批**（G1 Turn 身份／G2 在飞链数量不变量／G3 Intent 值对象）——须 ADR-016 规则 1 域归属卡，且必须后于纠偏批：`roundOrdinal` 需要单一 ++ 点才有单调源。
4. **原阶 C 前置审计 §4 的三条落点（C1 信封／C2 恢复三判／C3 规则归 main）不作废，但降为"C-补模批"的子项**——在拓扑未收口前写这些字段＝给不存在的概念补列（该判断见分家表 §5）。
5. **R3（agent loop 下沉 main）记 V2，本批不做**：R2 是 R3 的前置——先把驱动权收到一个对象上，才谈得上把它搬进程。
6. **R1（维持多入口、只补可观测字段）判为不可作为收口**：它使归属可被观测，但不使归属被决定；抢跑窗口（≤500ms＋一个 tick）原样保留。

## Consequences

- **正面**：族红的处置从"再审一轮补丁形状"转为"按既有权威文本回归"——判据是现行文档原句，不是新发明；A/B 两轮的实测数据首次获得统一解释（同一台机器的两面）；§4.5 C1/C3/C4/C7/C10 五条契约从此有实现地基（投递模式与消息状态需要一个持有者才能成为数据）。
- **代价**：纠偏批改动面大（26 站点收敛＋`maybeContinue` 语义收窄＋busy 改派生）；**轮序变动预期打到 ≈6–8 例把轮序当标定的桩**（`retry:188`/`core:388`/`factory.self:30`＋`:73` 等）——须按 `02 §4.12`＋`04 §3.2:412` 逐条重标并附证据，**禁止以"让它绿"为目标改断言**（阶 C 审计 §4.5 口径不变）。
- **风险登记**：D4 待授权直送例外与 D5 催推进功能在收口通道时最容易被"顺手统一掉"——两者均为已裁语义，纠偏批的 DoD 须各含一条"仍在位"的断言。
- **边界**：本 ADR 只裁性质与批次顺序，**不含 scheduler 的接口设计**（属 C-纠偏批的提案，须另出并过 ADR-016 规则 1）；不含实现改动。
- **测批纪律**：ADR-012 全程有效——落地前后仍走「整轮测批 → 汇总 → 用户裁决 → 另开修批 → 另开回归」。
