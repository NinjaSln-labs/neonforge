## 2. Hero 文案

- **主标题**：你之所向，我之所往；你之所定，我之所行。
- **副标题**：为 DeepSeek 打造的 AI 问题工作台——说出你的问题，拿到结果。
- **CTA**：下载 macOS 版 · 加入候补名单
- **一行说明**：说问题 → 澄清目标 → 确认方案 → 分步授权执行 → 解决确认（证据对账）→ 交付产物 + 指导。

## 3. 机制区（产品方式——每一步都有门槛）

| 卡片 | 文案 |
|------|------|
| 确认卡 = 推进门槛 | 目标 / 方案 / 解决三处结构化确认——未确认时模型停在确认点，不越级、不白做 |
| 分步授权 | 写文件、执行命令逐项授权（风险明示 + 写前快照可回滚）；高危命令永远单独确认 |
| 宿主强制边界 | 模型只能写批准清单内的文件（approve-files 批量授权）；清单外写入被拒并提示边界 |
| 问题 = 一等公民 | 问题台账 + 会话快照 + 断点续做 + 复跑——批准清单跨重启保留 |

## 4. 亮点区

1. **快**：KV 缓存预热——首字延迟 275ms → 118ms（打开项目即「热着」）
2. **省**：LSP 精准上下文——不倾倒垃圾 token，1M 上下文用在该用的地方
3. **深**：单模型深度集成——前缀确定性、成本算得清、工具链路一致（详见 Blog 系列）

## 5. waitlist 收集

- **目的**：跨平台（Windows/Linux）开放通知、新功能（信任分级/多模型网关）抢先体验
- **字段**：邮箱（可选 + 平台意向）
- **落点**：待定（自建表单 / Google Form / GitHub Discussions）——拍板项
- **隐私**：仅用于发布通知——不营销轰炸
