How it works

每一步都有门槛，模型不越级、不白做

目标、方案、解决三处结构化确认卡——未确认时模型停在确认点等你拍板；执行全程分步授权，写前快照可回滚。

确认卡 = 推进门槛

三重结构化确认

目标 / 方案 / 解决三处确认卡。未确认时模型停在确认点——不越级、不白做，你的意图说了算。

分步授权

风险明示，写前快照可回滚

写文件、执行命令逐项授权；高危命令永远单独确认。每一步你都知道模型要做什么。

宿主强制边界

清单外写入被拒

模型只能写批准清单内的文件（approve-files 批量授权）；清单外写入被宿主直接拒绝并提示边界。

问题 = 一等公民

断点续做，跨重启恢复

问题台账 + 会话快照 + 复跑。批准清单跨重启保留——关掉应用再打开，接着上次的边界继续。

What it is

它不是 IDE，也不是 Chatbot

不是 IDE

不替你写代码项目，不需要你会编程——它围绕「你的问题」组织工作。

不是 Chatbot

不靠一段段对话碰运气——确认卡、授权、证据对账把过程变成可验收的交付。

是问题工作台

说出问题，拿到结果：产物 + 每步确认记录 + 可验证的证据。非技术者能拿到东西，开发者能得到紧凑的审批回路。
